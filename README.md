**Live Demo:** [proballarena.vercel.app](https://pro-ball-arena.vercel.app)

## Overview

ProBallArena is a website created for a client who owns a sports facility. It serves as an online platform to provide information about the facility, including booking options, available sports, schedules, and much more. The project is built using modern web technologies to ensure a responsive and user-friendly experience.

## Features

- **Interactive Components:** The application includes various interactive components to enhance user engagement.
- **Responsive Design:** Optimized for various screen sizes to ensure a seamless experience across devices.
- **Modern Tech Stack:** Utilizes the latest technologies for optimal performance and maintainability.
- **Facility Information**: Detailed pages about the sports facility, including services offered, amenities, and pricing.
- **Booking System**: A user-friendly booking system to schedule courts and facilities.

## Technologies Used

- **TypeScript:** Ensures type safety and enhances code quality.
- **Next.js:** A React framework that enables server-side rendering and static site generation.
- **Tailwind CSS:** A utility-first CSS framework for rapid UI development.


## Project Structure
- **app/:** Contains the main application components and pages.
- **components/:** Reusable UI components used throughout the application.
- **hooks/:** Custom React hooks for managing state and side effects.
- **lib/:** Utility functions and libraries.
- **public/:** Static assets such as images and fonts.
- **styles/:** Global and component-specific styles.
